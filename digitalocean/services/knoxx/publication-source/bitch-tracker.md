BitchTracker

BitchTracker is a client plugin for a chat platform, built from the same ClojureScript toolchain as the rest of the constellation.

It is included here because it is honest about scale. Not every piece of a body of work is a platform or a substrate. Some of it is a plugin that has to fit inside somebody else's plugin format, obey the shape that format demands, and do one useful thing.

Its governing rule is exactly that: whatever the source looks like, the distributable artifact must stay in the exact shape the host expects. A plugin that is elegant internally and unloadable externally has failed at the only requirement that was never negotiable.
