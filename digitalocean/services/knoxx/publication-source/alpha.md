Alpha

Alpha is the structural integrity layer. It answers deterministic questions about whether a thing is well formed, before anything else is allowed to depend on it.

The questions are deliberately narrow. Is this artifact shaped lawfully. Does this reference have a stable identity. Is this relation explicit and attributable. Is this event structurally usable. None of these ask whether something is good, correct, or a wise idea. They ask whether it is coherent enough to be reasoned about at all.

Separating that from judgment is the whole point. A system that mixes is this well formed with is this what we wanted produces failures that are hard to attribute, because a malformed input and a bad decision arrive looking the same. Alpha runs first, refuses clearly, and lets evaluation be about evaluation.
